## Search note
Brave Search API key works for web lookups: `curl -s "https://api.search.brave.com/res/v1/web/search?q=<query>" -H "X-Subscription-Token: <key>" -H "Accept: application/json"`. Beware: a "Eden catalog PDF" found via search was a *different* company (Eden retail shelving, Czech/UK) — verify the domain is eden-design.de before trusting results.

## MSDS sourcing (substrate vs chemicals)
For the CuZn37/C27200 brass substrate, a ready SDS is available online from any manufacturer of the same alloy — e.g. **Robert Laminage SA** (Switzerland): `https://www.robertlaminage.com/sites/default/files/msds/MSDS_370_Brass_CuZn37.pdf` (6 pages, confirms CuZn37/C27200, "no special measures required" — non-hazardous solid). KME's own site may time out; the same-alloy SDS from another maker is an acceptable interim reference. The **patination-chemicals** SDS is proprietary to Eden-Design and must be requested from them (Rev.02 addendum).

# MOC_HQ CRS Template — Structure & Filling Notes

The official Comments Resolution Sheet (CRS) template the user supplies for material submittal comment responses. Deployed at:
`https://samaya-factory.com/assets/templates/CRS_Template_MOC_HQ.xlsx`

## Template structure (sheet "CRS")

- **Header block (rows 1-7):** PROJECT NAME, CRS NUMBER, Rev, DATE, DOCUMENT No., DOCUMENT TITLE, DOCUMENT TYPE, DISCIPLINE. Merged cells A:C, D:H, I:J, K:Q per row.
- **Legend (rows 8-9):** Comments/Replies Legends & Status.
- **Comment table header (row 10):** `No. | Initial | Sheet | Reviewer Comment (D:H) | Originator Reply (I:N) | Reply By (O) | Reply Status by Reviewer (P:Q)`.
- **Comment rows (11-41):** one row per CG comment. Columns D:H = reviewer comment, I:N = originator reply, O = reply-by name, P = reply status.
- **Status legend (rows 42-50):** A=Approved, B=Approved With Comments, C=Revise and Resubmit, D=Rejected, F=For Information. Sign-off block for SC / PMCM / MOC / Originator.

## Filling rules

- Fill header: PROJECT NAME = "Regional Museum (Aseer)", CRS NUMBER = `CRS-<DocRef>-Rev<XX>`, DOCUMENT No. = the submittal ref (e.g. MOC-MUS-ASE-1A0-MA-0007), DISCIPLINE = Architectural.
- One row per CG comment. Keep the reviewer comment verbatim in D:H; put the originator reply in I:N.
- **Reply Status by Reviewer (P) is filled by the CONSULTANT, not the originator** — do not present our "Closed/Open" as final; it's a provisional status until CG reviews.
- Save as `CRS_<DocRef>_Rev<XX>.xlsx` in the submittal's Rev folder (e.g. `.../Brass_Patinated_Sample_GH/MA-007 Rev01/`).

## MA-0007 (Patinated Brass) compliance pattern

CG Code C (02-Jul-2026) required 10 items. Compliance split:
- **COMPLIED (5):** NRS comments · all applications (not just showcases) · manufacturer details (Glasbau Hahn, PQ-0063 Code B) · **Oddy test (PASS — NonaChem T2607222, 21-Aug-2026, P/Permanent on Ag/Cu/Pb)** · chemical composition (CuZn37/C27200 KME datasheet).
- **PENDING → Rev.02 addendum (4):** MSDS · VOC · off-gassing · fire-rated report — all Glasbau Hahn lead-time items.
- **PARTIAL (1):** 2 alternative samples — Option A IGP 591T PARKOUR powder coat (submitted), Option B PVD (in development).

**Strategy:** submit Rev.01 on the strength of the passed Oddy test (the decisive blocker), commit the remaining certs as Rev.02 with a date. Push back technically on fire-rated (brass is non-combustible) and off-gassing (covered by Oddy) rather than blindly complying.

## Patinated brass applications (for the sample page / submittal)

From Finishes Schedule 6930 (Rev A) + Graphic Schedule:
- FI_ME_01: walls, main gallery doors, door reveals, setworks (display units/frames/AV), reception desk
- FI_ME_03: floorbox trims
- FI_GR_11: wayfinding signage
- FI_ST_03: reception feature wall detailing
- Graphic Schedule: ~145 room-introduction graphics on brass substrate across galleries G1–G14
- Showcase external panels (2mm patinated brass) — RFI-0019 proposes substituting with powder-coated steel

**Data provenance caution:** the sample page's original 7 applications (cladding, door hardware, handrails, screens, joinery, lift lobby, signage) were generic/assumed, NOT sourced from the schedules. Always verify applications against the approved Finishes/FF&E/Graphic schedules before updating the sample page — do not trust the existing page content.

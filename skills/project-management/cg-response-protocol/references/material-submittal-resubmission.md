# Material Submittal Resubmission Strategy (Code C → Rev.01)

Class-level approach for responding to a CG Code C (Revise & Resubmit) on a material submittal, learned from MA-0007 (Patinated Brass, Glasbau Hahn).

## Core principle: classify each CG comment, don't blindly comply

When CG rejects a material submittal, its comments are NOT all equally valid. Sort them into three buckets and respond differently:

| Bucket | Meaning | Response |
|--------|---------|----------|
| **COMPLIED** | We have the evidence now | Attach it, mark Closed |
| **PENDING** | Legit requirement, evidence on supplier lead-time | Commit to a dated Rev.02 addendum, don't hold Rev.01 |
| **PARTIAL / OVER-REQUIREMENT** | CG applied a generic checklist without technical basis | Raise a documented technical objection |

## Technical pushback on over-requirements (metal finishes)

CG often demands a full generic certificate list for metals. Several are technically unjustified — push back with documented reasoning:

- **Fire-rated report on a metal** — metals are non-combustible. Fire-rating matters for combustible materials (fabric, wood, plastic). Requesting it for brass/steel = checklist application without thought.
- **Off-gassing test when Oddy already passed** — the Oddy test already detects corrosive/volatile emissions (silver=sulphur, copper=chlorides/oxides, lead=organic acids). A passed Oddy makes a separate off-gassing test redundant.
- **2 alternative certified manufacturers for a single-source material** — if the supplier confirms only ONE global source exists (documented in a supplier letter), the request is impossible. Offer supplementary finish options (e.g. powder-coat, PVD) as choices, not substitutions, and cite the supplier letter.

## The decisive fix: Oddy test

For museum materials, the Oddy test (material compatibility for conservation) is the highest-risk item that drives Code C. A **PASS (Permanent)** on silver/copper/lead coupons is the strongest evidence to flip a Code C → Code B/A. Lead the resubmission with it.

## CRS sheet structure (MOC_HQ template)

- Header: doc no, Rev, title, date, submitted by, CG reviewer, previous status, reference
- One row per CG comment: No / Initial / Sheet / Reviewer Comment / Originator Reply / Reply By / Reply Status
- Reply Status column is filled by the REVIEWER (CG), not the originator — mark our intended status but CG decides final
- Summary block: count Complied / Pending / Partial + the outcome requested

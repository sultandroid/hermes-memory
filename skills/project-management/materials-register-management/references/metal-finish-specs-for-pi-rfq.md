# Aseer Metal Finish Specs — for PI / RFQ / Sample Requests

Canonical spec text for the two Aseer Museum metal finishes, ready to drop into
proforma invoices, RFQs, and sample requests to suppliers. Source: EDEN brass
datasheet (SAM-FIN-PB-001) + SS PVD folder label (SAM-FIN-SS-002, MOC-MUS-ASE-1A0-MA-0008).

## 1. Brass — Patinated Effect (EDEN CD/CC)

```
Base: Brass MS63 (CuZn37), stress-free, custom-planed, architectural quality
Size: 200 x 200 mm (adjust per request)
Thickness: 2 mm
Surface: EDEN-CD/CC "RANDOM-CLOUDY" burnished, clear coat sealed
Cut edges: burnished and lacquered
Protection: with protective film
Note: chemically darkened non-ferrous metal — slight colour variation possible
      within piece and batch (inherent material property, not grounds for complaint)
Oddy testing: required (museum grade)
```

## 2. Stainless Steel 304 — Patinated Effect, PVD Finish

```
Grade: AISI 304 (EN 1.4301)
Size: 200 x 200 mm (adjust per request)
Thickness: 2 mm
Surface: brushed / satin finish
Finish: PVD (Physical Vapour Deposition) coating, patinated / antique brass effect
Colour: dark patination (to match reference visuals)
Oddy testing: required (museum grade)
```

## Notes

- **PVD is production-line controlled** — unlike EDEN's batch chemical patination,
  PVD eliminates batch-variation risk. Preferred as the risk-mitigation alternative
  (see `patinated-brass-datasheet-eden-analysis.md`).
- **Oddy testing is mandatory** for museum-grade materials inside showcases.
- The EDEN datasheet's disclaimer language ("final appearance is not a basis for
  complaints") must be disclosed to CG, never hidden.
- When splitting a PI into per-material line items, keep the **total unchanged** and
  derive unit price = total / total qty. E.g. US$522 for 8 samples (4 brass + 4 SS)
  = US$65.25/sample.

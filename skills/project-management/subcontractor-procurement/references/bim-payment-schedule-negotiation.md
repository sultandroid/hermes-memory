# BIM Payment Schedule Negotiation — Worked Example (Radiance Group, Aseer Museum)

Session: 2026-08-22. Countering a BIM subcontractor's calendar-date payment schedule.

## Context

- **Vendor:** Radiance Group (Dr. Waleed Salah, BIM Manager/Design Manager)
- **Contract:** Proposal R01, 02-Aug-2025, total **USD 20,000** (PO P00555 / ASR-SAMAYA-CON-0002-ISS-R02)
- **Paid to date:** USD 6,500 (32.5% = Advance/Mobilization + Phase 01 LOD 350 audit)
- **Outstanding:** **USD 13,500**
- **Vendor's revised letter (16-Aug, Ref RAD/SMY/AMA-2026/003):** 3 × USD 4,000 (31-Aug / 30-Sep / 31-Oct) + USD 1,500 on COBie delivery = 13,500 ✓

## The negotiation

Vendor claimed they carried a reserved team through a stalled period and requested a "fair resolution" (23-Jul letter). They proposed calendar-date instalments.

### Counter-schedule (deliverable-linked, sums to 13,500)

| Instalment | Trigger (Delivery + Acceptance) | Amount |
|---|---|---|
| Advance / Mobilization | On acceptance of revised schedule (concession for carried team) | USD 1,500 |
| 1st | Federated LOD 400 model (Arch + Struct + Mech/duct + Elec), free of critical clashes per BEP CL-01..05 | USD 2,000 |
| 2nd | Clash Detection Report — CL-01..05 resolved & verified | USD 4,000 |
| 3rd | 4D (schedule-linked) BIM — no later than 15-Sep-2026 (before 30-Sep handover) | USD 4,000 |
| Final | LOD 500 As-Built + COBie dataset, handover-ready | USD 2,000 |
| **Total** | | **USD 13,500** ✓ |

### Key moves
1. **Concede USD 1,500 advance/mobilization** on acceptance — recognises the carried team, cheapest concession.
2. **Counter the "no approvals" claim** with approved design input from the submittal register: Plumbing 1M0-1G-0002 (Code B, 04-Aug), Fire Alarm & Fire Suppression MEP-ZD-0067 Rev.03 (Code B, 06-Aug), HVAC 1M0-1G-0001 (deemed approved). Mechanical approved since early August → LOD 400 could start immediately.
3. **Defer 5D (cost-linked) BIM** and remove architectural modelling — retain vendor as consultant for those areas only. Reduces their resource load and our cost.
4. **Re-time 4D** to precede the 30-Sep handover (post-handover 4D has no value).

## Pitfall that bit us

**Arithmetic drift.** An earlier draft raised the final retention from USD 1,500 to USD 4,000 without rebalancing → total became 14,000 ≠ 13,500. The user caught it. **Always re-sum the counter-schedule against the verified outstanding balance before sending.**

## User style preference

Keep the reply SIMPLE and direct: (1) scope reduction/concession, (2) payment split table, (3) one line that approved input is available now. Do NOT build a 5-part essay with "key changes vs your proposal" tables unless asked. Lead with what you're giving them, then the schedule, then the expectation.

## Source of truth for approved design input

The submittal register (`01_Registers/submittal_register.md`) is the authoritative source for which packages are Code B / deemed approved. Check it before drafting the "input is available" claim — never assert approvals from memory.

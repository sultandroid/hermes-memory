# Cloud Survey — Dismantling vs Demolition Scope Interpretation

## The core distinction (Aseer Museum, Aug 2026)

When the user asks "can we start the structural cloud survey / break the cladding (marble/gypsum) to measure columns?", the answer hinges on **Dismantling (تفكيك) vs Demolition (هدم)** — they are NOT the same and have DIFFERENT approval statuses:

| Activity | Status | Governing doc |
|----------|--------|---------------|
| **Dismantling** (فك + إعادة تركيب) for cloud survey / structural measurement | ✅ **Approved** | ZD-0106 (Code B, 25-Aug-2026) |
| **Demolition** (هدم نهائي) | ❌ **Blocked** | EXEC-03 (04-Aug-2026) — "no construction/demolition until design complete" |

**Key insight:** Approving the dismantling plan (ZD-0106) does NOT lift the demolition block (EXEC-03). They are compatible, not contradictory — the consultant explicitly widened dismantling and narrowed demolition. The CG comment sheet for ZD-0106 states verbatim: *"The Contractor is permitted to dismantle and reinstall only. No demolition works are allowed."*

## Why the PM may not have started

The PM likely holds back because:
1. **EXEC-03** (from MoC + PMC + CG) blocks demolition — PM reads it conservatively.
2. **ZD-0032 (Demolition routing plans) is still Code C** — PM waits for its approval before touching anything, not realising dismantling-for-measurement is already permitted under ZD-0106.
3. **Concrete core test results** may be pending/negative (see below) — PM waits for structural confirmation.

**Resolution:** The contractor CAN start dismantling cladding for measurement under ZD-0106 — no need to lift EXEC-03, no need to wait for ZD-0032. Conditions: coordinate with the consultant's site team, reinstate everything after measurement, floor samples only 20×20 cm (not full floors), any damage to MEP/suspended ceilings is contractor's responsibility.

## ZD-0032 (Demolition routing plans) — what it actually is

- **Rev.00** submitted 12-May-2026 (Adel Darwish) → CG Code C 13-May-2026.
- **Rev.01** resubmitted 25-Aug-2026 (Waris via Hesham) → still Code C.
- **All 28 comments are HSE-only** — NO drawing changes required. The required deliverables are: Method Statement + Risk Assessment (slab cutting, gypsum removal, ceiling dismantling, glass removal), structural assessment/clearance from a qualified engineer, Lifting Plan, waste management plan. The rest (dust control, LOTO, PTW, crane certs, ~150m debris transport, fire/emergency) get folded into the MS/RA.
- **So ZD-0032 does NOT block dismantling-for-measurement** — it only blocks actual demolition.

## Concrete core test risk (Ahmed Gad, 06-Aug + follow-up)

Ahmed Gad (CG structural) requested: (1) As-Built column dimensions (on-site measurement of highlighted columns), (2) Material testing quotations (Concrete Core + Geotech/Soil Borehole), (3) Big Stone technical report. These feed the STR structural model and the ZD-0114 Code C response.

**ZD-0114 (Structural Analysis & Design tracker) Code C comments** — all gated on the cloud survey / core tests:
1. Discrepancy between structural member sections/reinforcement in model vs as-built drawings.
2. Model based on contract as-built — must be confirmed after cloud survey approval.
3. Column fc' (concrete compressive strength) must be confirmed after concrete core test results.
4. Foundation structural model to be submitted for review.
5. Design calculation sheet for unsafe elements.

**Aug-2026 escalation:** Ahmed Gad reported a "big problem" — concrete core tests showed the concrete is weaker than required, affecting ~60% of design effort. The full report had not yet arrived. This is a major structural-design risk: the STR model is built on an assumed fc' that the actual concrete may not meet. Treat as a live risk until the test report is received and the design impact is quantified.

## Workflow preferences observed (user)

- **Always give the document ref + title** when discussing a submittal — the user asks "ابقي اكتب عنوان التقديمه علشان اعرف انت بتتكلم عن ايه" (write the submission title so I know what you're talking about). Lead with the MOC-MUS-ASE ref + short title.
- **Plain Arabic for explanations** — "قولي بالبلدي" (tell me in plain language). Strip technical jargon; use simple Arabic with a clear verdict first.
- **Make a plan and follow it** — "اعمل خطه لاي مهمه ادهالك وامشي عليها" (make a plan for any task and follow it). Use the todo tool and report progress against it.
- **Answer the direct question first** (e.g. "اتوافق عليها ولا لا" = is it approved or not) — give the yes/no verdict immediately, then the nuance.

# Excel Snapshot Template — Build Details

## Layout (Dashboard sheet)

The Samaya-styled Excel is built by `build_xlsx.py` (shared) + register-specific build scripts.

| Row | Content |
|-----|---------|
| 1 | QR code (col A, 55px), Title (cols C-F), Logo (col G) |
| 2 | Doc No · Contract · Rev · Status |
| 3 | Snapshot No · Date · Time · Source URL |
| 5-6 | KPI strip: TOTAL, CRITICAL, HIGH, MEDIUM, LOW, OPEN |
| 9 | QR caption |
| 11 | RISK MATRIX header |
| 12+ | Matrix: P↓/S→ header + data rows with COUNTIFS formulas |
| Next | BY RATING table |
| Next | BY STATUS table |
| Next | Donut chart (right side) |
| Next | EXPOSURE BY CATEGORY table + bar chart |
| Last | TOP OWNERS table + footer |

## Zero Merged Cells

All merged cells have been removed. Every cell is individual.

## COUNTIFS Matrix Formulas

The risk matrix uses dynamic COUNTIFS formulas:
=COUNTIFS('Risk Register'!$C$12:$C$last_row,p,'Risk Register'!$D$12:$D$last_row,s)
Column C = P/Consequence, Column D = S/Likelihood.

## P and S Columns in Risk Register

Must include P (probability/consequence) and S (severity/likelihood) as separate columns (positions 3-4 in REG_COLS).

## Matrix Labels by Register

- PRR/DDR/AVR: "P ↓ / S →" with "S1..S{scale}"
- HSE: "C ↓ / L →" with "L1..L{scale}"
Controlled by `data.get("is_hse")` flag.

## HSE Field Mapping

Both build_hse.py and build_snapshots.py must map HSE-specific fields:
- activity → title
- hazards → cause, consequence
- controls → response_action
- l_init → probability (likelihood)
- c_init → severity (consequence)
- score_init → score
Also set is_hse=True and rbs_categories={"HSE": "Health, Safety & Environment"}.

## REG_COLS (no EVIDENCE column)

ID, Cat, P(5), S(5), Rating(10), Score(7), Status(11), Owner(18), Target(12), Risk Event/Title(38), Cause(34), Consequence(34), Response/Action(38)

## Known Issues

- AVR build_av.py has keyword-args bug in _build_xlsx() call
- AVR snapshots not generated by build_snapshots.py (handled by build_av.py)
- HSE "OPEN" KPI shows 0 because HSE uses "Ongoing" status

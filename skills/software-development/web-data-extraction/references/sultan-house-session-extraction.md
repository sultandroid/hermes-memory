# Worked Example: Sultan House (Building 210) Finishing Works Dashboard

Full extraction of data and documents from a password-protected React SPA project management dashboard, including file download from Supabase and vision analysis of scanned documents.

## Target

`https://land210.vercel.app/` — A React SPA project tracking dashboard for "Building 210 Finishing Works" (عمارة 210), built by i360code, using Supabase for storage.

## Extraction Steps

### 1. Login

```python
browser_navigate(url="https://land210.vercel.app/")
browser_type(ref="@e4", text="user@email.com")     # email field
browser_type(ref="@e5", text="password")            # password field
browser_click(ref="@e6")                            # login button
```

Wait for redirect. Verify with `browser_snapshot()` — look for nav buttons (لوحة التحكم, بنود الأعمال, etc.).

### 2. Extract Dashboard Data

The snapshot captures financial KPIs: total expenses, office fees (10%), total paid (4 installments), available balance, contract value.

### 3. Navigate Sections via Console

The SPA's accessibility tree doesn't update on route change. Use programmatic clicks:

```javascript
// In browser_console expression:
document.querySelectorAll('button').forEach(b => {
  if (b.textContent.trim() === 'بنود الأعمال') b.click();
});
// Then extract:
document.body.innerText
```

Repeat for each section: work items (40 items), payments (4 installments), reports, legal files (15 documents), stages, users.

### 4. Save Raw Text to Disk

```python
write_file(path="/Volumes/MIcro/.../00_dashboard.txt", content=extracted_text)
write_file(path="/Volumes/MIcro/.../01_work_items.txt", content=extracted_text)
# etc.
```

### 5. Extract File Download URLs

```javascript
document.querySelectorAll('a[href*="supabase.co"]').forEach(a => {
  console.log(a.textContent.trim(), '|', a.href);
});
```

This yields Supabase Storage URLs like:
`https://hygqhdeofgazasjvkuxo.supabase.co/storage/v1/object/public/documents/documents/1779395394748-clwqft.pdf`

### 6. Download All Files via curl

```python
files = [
    ("contract.pdf", "https://supabase.co/.../doc.pdf"),
    ("receipt.jpg", "https://supabase.co/.../img.jpg"),
    # ...
]
for name, url in files:
    terminal(f'curl -sL -o "{target_dir}/{name}" "{url}" -w "%{{http_code}}"', timeout=60)
```

### 7. Delegate Document Analysis

Scanned PDFs have no extractable text. Worker agent should:

1. Attempt `pdftotext` first (in case it has real text)
2. If empty, convert to images with `pdftoppm` or use `sips` on macOS
3. Use `vision_analyze` to read each page/image
4. Produce structured MD files: contract summary, BOQ estimate, account statements, payment receipts, contractor quotations

Bond type codes used in this project:
- `MST` = مستخلص (progress certificate) — 186,345 EGP across 18 items
- `TWD` = توريد (material supply) — 213,240 EGP across 17 items
- `SRF` = صرفية (cash disbursement) — 15,000 EGP across 5 items

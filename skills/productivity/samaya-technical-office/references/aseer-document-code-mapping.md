## Document Prefix Convention

Full format: `MOC-ASEER-SIC-[Volume]-[Type]-[Serial]`

| Component | Example | Meaning |
|---|---|---|
| Project | MOC-ASEER-SIC | Ministry of Culture × Aseer × Samaya |
| Volume | 1K0 | General/Management (1A1=Arch, 1M1=MEP, 1S1=Structural, 1E1=Electrical, 1B1=BIM, 1Q1=Quality, 1H1=HSE) |
| Type | PL | Plan (DR=Drawing, MS=Method Statement, SP=Specification) |
| Serial | 0015 | Sequential |
| Rev | 04 | Revision number |

## Reference Style

- **Halftone annotations** (gray italic under section headings): Use short codes: `PL-0015 Rev 04 sec 19` not the full prefix.
- **Body text**: Use full formal codes on first mention per section, short codes thereafter.
- **CRS responses**: Reference by formal code, e.g., "per PL-0015 Rev 04 sec 21".
- **Contract number**: Always full `Contract 0010003521` — never truncate to "Contract 0010".

# Training & Learning — Index

> **Purpose:** A dedicated area for the user to build up domain expertise by studying real cases, contract precedents, and arbitration rulings. **Distinct from** `references/` (cross-entity facts) and project memory (live work).
>
> **What goes here:** real cases (anonymized or public), extracted lessons, terminology notes, "lessons learned" reading notes, and links to similar cases found online.
>
> **What does NOT go here:** live project work, source-verifiable facts about user's projects, credentials, anything entity-specific from active work.

## How to use

1. **User pastes a case PDF** → I extract the facts, structure, and lessons → save to a subdirectory
2. **User asks "find similar cases online"** → I search, summarize, and add to the same subdirectory
3. **User asks a contract/claims question** → I search THIS directory first, then online, then answer
4. **User says "lesson: X"** → I add it to the topic-level `LESSONS.md` (curated wisdom, separate from raw case data)

# Contract Administration Vocabulary — Arabic ↔ English

> **Topic-specific terms.** General construction terms are in `../vocabulary.md` (cross-topic). Terms here are specific to Contract Administration.
>
> **Legal weight legend:** ✅ strong · ⚠️ defensible · ❌ weak · n/a = not a claim

| English | Arabic | Legal weight |
|---|---|---|
| VO / Variation Order | أمر تغيير | ⚠️ Defensible if properly issued |
| EOT / Extension of Time | تمديد مدة العقد | ⚠️ Defensible if justified |
| Time bar | سقوط الحق | ✅ Strong — strict contractual deadlines |
| Notice of claim | إشعار بالمطالبة | ✅ Strong — preserves rights |
| Scope creep | تعدي على النطاق | ❌ Weak — usually no entitlement |
| Provisional sum | مبلغ احتياطي | ⚠️ Defensible with proper documentation |
| Daywork | عمل باليوم | ⚠️ Defensible if pre-authorized |
| Force majeure | قوة قاهرة | ✅ Strong if properly invoked |
| Suspension of work | وقف الأعمال | ⚠️ Defensible if properly notified |
| Termination | إنهاء العقد | ✅ Strong if per conditions precedent |
| Conditions precedent | شروط موضعية | ✅ Strong — strict |
| Determination | تقييم العقد (FIDIC) | ✅ Strong — FIDIC-specific |
| Engineer's Representative | ممثل المهندس | n/a |
| Contractor's remedy | تعويض المقاول | n/a |
| Employer's remedy | تعويض صاحب العمل | n/a |

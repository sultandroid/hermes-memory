## 5-Lesson Extraction Pattern (consistent across all cases)

Each case file applies the same five-axis lesson grid, calibrated for design management:

1. **Vocabulary** — the precise term (Arabic + English + legal weight) and what it does *not* mean
2. **Evidence** — the specific document, date, log, or artefact that proves or disproves the point
3. **Procedural** — the named workflow or process that the case implies
4. **Strategic** — the choice the design manager has to make at the gate the case discusses
5. **The principle** — the one-sentence rule the case is really trying to teach
